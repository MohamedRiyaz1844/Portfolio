# 💼 My Developer Portfolio

This is my personal portfolio website built with **React**, **TypeScript**, and **Tailwind CSS**. It showcases who I am, what I'm learning, and where I'm heading as a developer.

---

## 🚀 Tech Stack

- ⚛️ React
- 🔷 TypeScript
- 🎨 Tailwind CSS
- 🌙 Dark/Light Theme Toggle
- 🛠️ Git & GitHub

---

## 📄 Features

- Hero section with a quick intro
- About me section
- Learning section (instead of projects)
- Responsive design
- Dark/light theme toggle
